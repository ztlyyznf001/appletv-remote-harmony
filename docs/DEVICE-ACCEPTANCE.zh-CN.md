# 真机验收清单

目前下列项目全部 **未运行**。只有实际观测到的项目才能改成通过；SDK 编译通过不能代替电视画面验收，模拟器通过也不能代替用户局域网。

记录：手机型号 / HarmonyOS 完整构建号 / API、tvOS 版本、路由器是否隔离客户端、App commit、OpenSSL 版本、执行日期。不要记录 PIN 或秘密。

## 构建与安装

- [ ] 官方 API26 SDK 完成 Native / ArkTS / HAP 构建，保留日志
- [ ] 目标 ELF 为 AArch64 / Harmony ABI，OpenSSL 版本与源码哈希可追溯
- [ ] 调试签名安装成功；启动后无 native load 崩溃
- [ ] 包内许可证齐全；无个人配置、密钥、明文凭据或 PIN

## 发现

- [ ] 同网能发现并显示 Apple TV；实际端口来自 resolve
- [ ] TV 重启 / IP 或端口变化后刷新为最新地址
- [ ] 同名设备不会被当作同一个已认证身份
- [ ] 非 Apple TV Companion 广播不显示已连接，不绕过 PIN
- [ ] 扫描时切后台 / 回前台不重复监听或复活过期服务
- [ ] 手动有效 IPv4 / IPv6（含需要的 scope）与实际端口可用
- [ ] 无效地址、缺端口、隔离网络、联网禁用显示错误，可再次尝试

## 配对与存储

- [ ] 正确 PIN 配对成功，再连接成功
- [ ] 错误 PIN 拒绝，不保存身份；再次配对可恢复
- [ ] PIN 页面取消、切后台、电视取消均关闭待配对连接
- [ ] 配对时连续点击只运行一组流程
- [ ] HUKS AES-GCM 保存后杀进程重启免重新输入 PIN
- [ ] 文件系统中只有密文；篡改 IV / tag / 密文 / 绑定信息后拒绝解密
- [ ] HUKS 密钥缺失时拒绝旧密文，不自动覆盖成明文或把失败当成功
- [ ] 同 IP 替换另一台电视 / TV 重置身份后明确拒绝旧身份
- [ ] 确认忘记配对后删除本机保存信息，再次连接要求配对

## 基础遥控

- [ ] 上、下、左、右各生效，方向对应正确
- [ ] 选择、返回、Home、播放/暂停各生效
- [ ] 连续点击不乱序、不无限排队、不重复重放
- [ ] 网络丢包 / 拒绝命令 / 畸形响应后 UI 不显示成功
- [ ] 按键期间切后台、锁屏、断网，不出现持续卡住的按键
- [ ] 下发按下后电视延迟回复时，释放不等满整个响应超时

## 生命周期

- [ ] 后台停止发现并关闭网络；无后台常驻服务
- [ ] 回前台有限重连；失败次数到上限后安静停止
- [ ] 主动断开后不会自动连回；用户明确连接后才恢复
- [ ] 快速后台/前台切换，旧 Promise / 旧计时器不会覆盖新状态
- [ ] 切换目标时旧连接不能向新设备下发按键
- [ ] Wi-Fi 切换后优先重新发现/解析，凭据仍需验证同一 TV 身份
